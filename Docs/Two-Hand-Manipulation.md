# 0.3.0 双手捏合调整展台

## 操作与边界

注视机车、零件、控制台或展台把手，左右手分别用拇指和食指捏合。两只手都保持捏合时：

- 两手中点的三维位移平移整个展台。
- 两手连线在水平面的角度变化，只绕世界 Y 轴旋转。展台围绕自身中心旋转，不倾斜、不翻滚。
- 两手实际间距的比例变化产生均匀缩放，绝对范围是初始大小的 26%–150%，重复抓取也不能越界。
- 松开任意一手立即停止；保留当前姿态。仍保持捏合的那一手不会转为单手点击或拆件，另一手重新捏合可开始下一次双手操作。
- 头部跟随的 FPS 面板不在变换根节点内，因此保持视野位置和字号。

## 输入与单手冲突

现有 PICO SpatialAdapter 6.1.0 的公开 `SpatialInputDevice`/`SpatialInputState` 提供 Pinch/IndirectPinch。应用仍需要至少一手的输入命中本展台；0.4.0 不再丢弃 SDK 已送达且位置有效的无命中捏合，可将其作为另一手。平台是否会持续送达完全未命中的手势需要真机验证，这不等于支持任意全局空中捏合。命中其他应用物体的输入不参与配对。

使用两个 PassThrough InputAction 收集有序事件。primary/secondary 并非固定的左手和右手，状态按设备 ID + interactionId 识别。双手几何使用 devicePosition；currentPosition 保留用于原有单手目标拖动，避免把两个落在同一目标上的命中点当作真实手间距。

单手动作有 0.28 秒的双手加入窗口；窗口内两手捏合优先进入整台调整，不触发按钮、车门或拆件。快速点按在释放时提交一次；重复 Began 不重复触发。第一手已操作较长时间后再加入第二手，则取消当前拖动/长按；已拆下的零件保留当前位置，不自动吸附。已完成的单手开关操作不会被追溯撤销。输入类型随最新样本更新，避免开始时是近距离触碰、后来转为捏合却始终不能加入双手操作。

松手、取消、输入设备消失和应用暂停均结束手势并清理占用。两手初始间距至少 7 厘米；进行中距离小于 4.5 厘米，或一帧跳变大于 40 厘米，则暂停当前调整。接近竖直的两手连线冻结旋转，恢复可用水平分量后重新建立角度基准，避免突然转 180°。变换使用短时平滑；释放后冻结，不继续惯性运动。

## 实现文件

- `SwanTwoHandManipulation.cs`：平移、Y 轴旋转、缩放约束、平滑和异常姿态检查。
- `SwanAtelierGestures.cs`：控制器 partial，双路事件、稳定 ID、双手优先、单手延迟及生命周期清理。
- `SwanAtelierController.cs`：原有按钮/拆装行为接入上述输入；FPS、高光和资源不改架构。
- `SwanAtelierGestureChecks.cs`：确定性输入样本与实际 Transform/控制器回归，合入现有 Play Mode 检查入口。

接口依据：知识库检索到的是 6.0 Kotlin 空间变换及设备姿态文档，不能直接作为 Unity API 示例；本项目采用本地 6.1.0 已公开的 Unity 类型及现有 Unity XRI/SeaInput 示例。对 SDK 的输入状态排序和生命周期做了只读核实，没有修改 vendor，也未引入私有调用。
