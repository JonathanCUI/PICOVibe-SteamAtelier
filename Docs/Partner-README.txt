桌上蒸汽工坊 · 伙伴继续开发工程
交付日期：2026-10-24

这是可以在 Unity 中继续编辑、开发、试玩和导出的完整源工程。
本包采用用户当前删改后的场景；原木桌及窗户等环境模型的移除已保留。
场景中仍有部分空的原环境层级和少量保留的装饰物；保持当前作者状态，没有重新生成场景。

打开方法
1. 完整解压本压缩包。建议放在本地短路径，例如 E:/UnityProjects/SteamAtelier。
2. 使用 Unity Hub 的“添加/从磁盘添加项目”，选择包内 Project 文件夹。
   应当能在这个文件夹下看到 Assets、Packages、ProjectSettings。
3. 使用 Unity 2022.3.5f1c1 打开（当前工程使用的准确版本）。
   不要直接以 Unity 6 等其他大版本升级原副本；需要升级时先另存副本。
4. 首次打开需要联网恢复 Packages 中声明的软件包，并重新导入素材、生成 Library。
   等待导入和脚本编译完成。
5. 打开 Assets/Atelier/Scenes/SteamAtelier.unity，点击播放。
   不需要运行任何场景生成脚本。场景已保存，可直接继续开发。

内容
· Project/Assets：全部当前资源、场景、模型、材质、贴图、字体、音效和 C# 源码；保留全部 .meta。
· Project/Packages：依赖清单及锁定版本；URP 14.0.8、TextMeshPro 3.0.6。
· Project/ProjectSettings：工程、渲染、输入、平台和构建设置。
· Reports/交付检查.json：导出时当前场景检查结果。
· 文件清单.json：包内源文件 SHA-256 校验清单。

主场景和源码
主场景：Project/Assets/Atelier/Scenes/SteamAtelier.unity。
桌面交互：Project/Assets/Atelier/Scripts/AtelierExperience.cs、AtelierControl.cs。
装配/传动/烟气/火花：Project/Assets/Locomotive/Scripts。
精细操纵台等生成源码：Project/Assets/Editor/Atelier。
Assets 下保留旧源场景、基础资源和生成工具所需的资产，方便后续开发。
其中 AtelierBuild.Run 会从源场景重新生成桌面场景，包括原来的桌子和房间。
要继续当前删改版，请直接编辑已保存的 SteamAtelier 场景，不要运行该重新生成方法覆盖它。
编辑器工具的报告/构建输出已使用随工程移动的相对位置，不要求存在 G 盘。

试玩操作
· 汽门横握柄：按住上下拖动；红色制动柄：点击停车。
· 换向柄：点击切换前/停/后；变向后重新加汽。
· 车灯、剖面、原地/行驶：点击对应开关；汽笛按住鸣笛。
· 重新装配：先打开保护盖，再按住红按钮 1.2 秒。
· 零件盘：分类旋钮/标签筛选，前沿左右拨片翻页，拿取零件拖到对应位置。
· 已装零件向外拖动可拆下；单击左/右车门或炉门可独立开关。
· 右键环视、中键平移、滚轮远近；F 总览，1 车头，2 内饰，C 剖面。
· W/S 加减汽，R 换向，空格制动，Esc 放下当前零件。
